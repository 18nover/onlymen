# OnlyMen Org Agents — Archive

This is an archived snapshot of the 13-agent AI engineering organization that
previously ran on the elizaOS framework in `eliza/packages/org/`. The `eliza/`
directory has been removed while other options for running these agents are
evaluated; the full agent definitions, knowledge base, shared standards, and
tooling source are preserved here for reference.

- `*.md` (this directory) — one profile per agent (generated from `characters/*.json`)
- `characters/` — raw agent configs: bio, full system prompt, personality, topics, style
- `knowledge/<agent>/` — per-agent domain grounding docs
- `shared/` — org-wide standards (coding, security, review process, escalation matrix, etc.)
- `skills/` — skill playbooks referenced by agent reviews
- `bin/`, `scripts/`, `tools/`, `package.json`, `biome.json` — the elizaOS-era
  tooling (CLI, doc generator, chat-ui control plane). **Inert** — it depends
  on `@elizaos/core` and the bun/elizaOS runtime, neither of which exist in
  this repo anymore. Kept verbatim as a reference for a future runtime.

Original doc header: one document per agent, generated by `bun run docs`
(`scripts/generate-agent-docs.ts`). These files are now static — the
generator no longer runs without the elizaOS toolchain.
