# OnlyMen

**Domain:** onlymen.gay  
**Company:** 18nover (18nover.gay)

Our own cleaner, modern alternative to RentMen. Fully owned. Not a clone, not a wrapper.

## Current Phase
**Phase 1** — Free for everyone (platform owner + any models who join).  
No subscription fees. Optional tips only.  
Grow first. Pricing decisions come later when the platform has real value.

## Core Principle
We are building a real company from day one. Documentation stays chronological and alive.
